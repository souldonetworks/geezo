## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Local build machine -> bun CLI subprocess invocations | `scripts/build-binary.js` shells out to a locally-installed `bun` binary; no untrusted remote input involved (manual/local-only build per PROJECT.md) |
| First-time cross-compile -> network download of target Bun runtime | Bun downloads the target platform's runtime from its own CDN on first use per target; this is Bun's own supply chain, not a new dependency introduced by this project |
