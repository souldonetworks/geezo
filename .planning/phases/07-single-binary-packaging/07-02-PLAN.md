<objective>
Build the asset-manifest generator script that walks the built frontend (`web/dist/`) and produces `server/generatedAssets.mjs` — an ES module using `import x from "<path>" with { type: "file" }` per discovered file, exporting a `manifest` object mapping URL path → embedded file path. This is the build-time half of PKG-03 (the compiled binary serves the frontend from this manifest instead of `express.static`).

Purpose: Bun's `type: "file"` import-attribute embedding only works from ESM `import` statements (verified in RESEARCH.md), so the manifest must be generated as static import statements at build time, not resolved dynamically at runtime.
Output: `scripts/generate-assets-manifest.js` (CJS, exports `generateManifestSource(distDir)` for testability + a `require.main` writer), its test file, and `.gitignore` updated so the generated `.mjs` and future `dist-bin/` build output are never committed.
</objective>
