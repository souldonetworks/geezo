<objective>
Build `server/cli.js`, the unified CLI entrypoint the compiled binary runs. It dispatches `serve` (starts the dashboard using `createApp()` plus an embedded-asset static-serving branch), `hook` (delegates to `runHookFromStdin()`), and `install-hook` (delegates to `installHooks()` with the binary's own path), plus `--help`/no-args/`--version`/unknown-command handling per CONTEXT.md's D-05 through D-13.

Purpose: This is the single file `bun build --compile` targets — everything the 5 platform binaries run through. It satisfies PKG-01 (dispatch), PKG-03 (embedded-asset serving), and PKG-06 (explicit error on missing generated assets), while reusing Plan 07-01's `runHookFromStdin()`/`installHooks()` exports without duplicating logic.
Output: `server/cli.js` (CommonJS, exports `dispatch(argv)` for testability) and `tests/server/cli.test.js`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| CLI argv (local user invocation) -> server/cli.js | Locally-supplied --port/--host flags are the only "input" crossing into server bind logic; not attacker-controlled remotely, but must not crash on malformed local input |
| server/cli.js serve -> server/generatedAssets.mjs (dynamic import) | Build-time-only artifact; absence must fail explicitly, not crash on unresolved import |
| server/cli.js install-hook -> ~/.claude/settings.json | Writes a shared config file Claude Code reads on every session start |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Denial of Service | server/cli.js serve (missing generatedAssets.mjs) | mitigate | Wrap `import('./generatedAssets.mjs')` in try/catch; print explicit instructional error and `process.exit(1)` instead of an unhandled rejection/crash |
| T-07-02 | Denial of Service | server/cli.js serve (--port validation) | mitigate | Validate resolved port is `Number.isInteger` and in range 1-65535 before calling `.listen()`; print `Invalid port: <value>` and return exit code 1 otherwise |
| T-07-03 | Information Disclosure | server/cli.js serve (--host 0.0.0.0) | mitigate | Default host is `localhost` (D-04) unless explicitly overridden; log a one-line startup warning whenever bound to a non-localhost host so LAN exposure is visible, not silent |
| T-07-04 | Tampering | scripts/install-hook.js (writes ~/.claude/settings.json) | mitigate — see Plan 07-01 | Preserved unchanged by this plan; server/cli.js's install-hook subcommand calls the already-hardened `installHooks()` without altering its backup behavior |

**Block on:** high severity (project default). All four threats have concrete, low-cost mitigations implemented directly in this plan's code (T-07-01/02/03) or inherited unchanged from Plan 07-01 (T-07-04) — none rated high.
</threat_model>
